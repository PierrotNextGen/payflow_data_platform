# payflow_data_platform
A production-inspired South African fintech payment platform built with FastAPI to simulate payment transactions for an end-to-end data engineering pipeline. The project will evolve into a complete Azure-based data platform with Bronze, Silver, and Gold layers, orchestration, infrastructure as code, and analytics.
